# Поддержка

Сначала выполните:

```bash
bash /opt/remnanode/installer.sh --check
```

В обращении укажите ОС, домен без секретных параметров, версию панели, стадию ошибки и очищенный вывод проверки. Дополнительно сообщите, отображается ли нода онлайн в Remnawave и работает ли тестовый VLESS-клиент.

- Ошибки и предложения: [GitHub Issues](https://github.com/himik0011113-afk/CheburNET-Vision-Installer/issues)
- Связь с автором: Telegram [@kopysovleonid](https://t.me/kopysovleonid)

Не отправляйте `SECRET_KEY`, `node.env`, приватные ключи и токены панели.
