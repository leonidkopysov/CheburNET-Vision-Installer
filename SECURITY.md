# Безопасность

Никогда не публикуйте `SECRET_KEY` ноды, `/opt/remnanode/node.env`, приватный ключ сертификата, токены панели или диагностические материалы с такими значениями.

Для обычной проверки используйте:

```bash
bash /opt/remnanode/installer.sh --check
```

Команда не выводит секретный ключ. При обращении приложите версию ОС, версию установщика и очищенный вывод проверки.

Сообщения об уязвимостях отправляйте автору лично: Telegram [@kopysovleonid](https://t.me/kopysovleonid). Укажите версию, условия воспроизведения и влияние. Не размещайте действующие ключи и рабочий эксплойт в публичном Issue.
