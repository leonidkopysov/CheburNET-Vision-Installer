# ЧебурNET Vision Installer 1.1.4

Исправлено длительное ожидание при настройке ZRAM после обновления системы. Операции APT и systemd ограничены по времени, ошибки сохраняются в журналах, а отложенный запуск после смены ядра отражается отдельным статусом.

- Для пакетов ZRAM добавлены таймауты APT, блокировки и сети, запрет удаления пакетов и журнал `/var/lib/cheburnet-tuning/zram-apt-*.log`. Уже установленные пакеты пропускаются; индекс обновляется не более одного раза и только при отсутствии нужного пакета.
- Во время тюнинга отключены автоматические перезапуски через needrestart. После таймаута APT новые установки в блоке ZRAM прекращаются с указанием проверить dpkg.
- Если найдено более новое ядро с загрузочным образом и модулем ZRAM, собственная служба включается для следующей загрузки. Отчёт указывает нужное ядро; существование старого ядра или общего `reboot-required` больше не считается достаточным основанием.
- Собственный сервис получил `TimeoutStartSec=90` и `TimeoutStopSec=15`. Setup ожидает появления устройства, ограничивает modprobe/mkswap/swapon и сохраняет уже инициализированный ZRAM без сброса и повторного форматирования.
- Внешний zramswap восстанавливается явным restart, а zram-generator — запуском swap-юнита. После таймаута systemctl отправляется запрос остановки без повторной постановки start в очередь. Вывод сохраняется в `zram-service-*.log`.
- Ошибки записи и включения службы не выдаются за успешно настроенный отложенный запуск.
- Исходники, встроенный payload и SHA-256 синхронизированы. Сборка явно использует UTF-8 и LF для одинакового результата на Windows и Linux.

Добавлены 22 изолированных регрессионных сценария ZRAM. Публикация выполняется GitHub Actions после полного набора тестов, воспроизводимой сборки, проверки Bash, ShellCheck и SHA-256. На VPS с настоящими systemd, ZRAM и перезагрузкой эта версия отдельно не проверялась.

Это выпуск установщика, а не автоматическая миграция работающей ноды. Сервер автоматически не перезагружается. Предыдущие релизы и теги сохранены.
