# ЧебурNET Vision Installer 1.1.4 — следующее изменение

Статус: подготовлено для проверки и тестовой VPS, не подтверждение готовности к эксплуатации

## Исправления безопасности и надёжности

- TCP/443 явно разрешается и при уже активном UFW; диагностика проверяет разрешения для используемых семейств и предшествующие запреты
- Диагностика Traffic Control и повторная проверка после repair возвращают ненулевой код при найденных проблемах
- Обновление TC сохраняет активное исключение ACME под общей блокировкой
- Исключение TC имеет ограниченный срок в nftables, а отдельный таймер удаляет просроченное правило UFW
- Ограничен охват каждого внешнего списка и объединения источников; отклонённое обновление не заменяет сохранённые списки
- Имя сертификата проверяется по результату проверки, а не только по коду выхода openssl x509
- Код 2 зарезервирован для ожидания панели/профиля, ошибки runtime возвращают 1, отмена — 130

## Установка и продолжение

- Проверка архива и доступные ранние проверки выполняются до изменений APT
- Пакеты безопасности и ZRAM готовятся общим механизмом; собственные установки пакетов Auto Tuning отключены
- Окружение APT и umask применяются также при --resume
- Штатный nginx маскируется до установки пакета и не должен запускать стандартный TCP-сайт
- Чисто отменённую установку TC можно повторить; частичные установки не удаляются автоматически
- Первоначальный SSH-снимок хранится отдельно от снимка текущей попытки
- Добавлен необязательный ввод IP входных и relay-нод

## Интерфейс

- Все запросы и приглашения ввода выделяются жирным жёлтым в терминале
- После установки сначала выводятся профиль и настройки хоста
- Затем появляется выделенный блок «Нода установлена и стала зелёной в панели?»
- «Да» запускает итоговую диагностику, «Нет» оставляет состояние ожидания без сообщения об ошибке
- Упорядочено меню TC; пункты белые, удаление красное; исправлены ответы Д/Н/Y/N
- Быстрая установка использует скачанный файл, вариант с SHA-256 сохранён

## Границы изменения

Auto Tuning остаётся исходным снимком 1.0.0. Traffic Control внутри Vision имеет редакцию интеграции Vision 1.1.4; самостоятельный репозиторий TC не изменяется. Рабочие серверы автоматически не обновляются, --resume не выполняет межверсионную миграцию

До выпуска обязательны CI и тестовая VPS по docs/TEST-REPORT.md. История Git и старые релизы сохраняются
