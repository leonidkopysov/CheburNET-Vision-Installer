# ЧебурNET Vision Installer 1.1.3

Выпуск добавляет защиту от входящих Two-Way Ping запросов и улучшает диагностику установщика.

- Добавлена отдельная таблица nftables `inet cheburnet_privacy`
- Блокируются входящие IPv4 echo-request, IPv4 timestamp-request и IPv6 echo-request
- Исходящий ping и остальные служебные типы ICMP/ICMPv6 сохраняются
- Правила восстанавливаются systemd до `network-pre.target` и проверяются после установки, при `--check` и после перезагрузки
- HTTP-проверки ограничены по времени и выводят понятные сообщения об ошибках соединения и TLS
- Добавлена явная проверка получения и формата digest образа ноды
- Для Python явно включён UTF-8

Auto Tuning 1.0.0 и Traffic Control 1.0.0 оставлены без изменений. Это новая установка для чистого сервера; автоматической миграции уже работающих нод нет.

Проверки и ограничения описаны в `docs/TEST-REPORT.md`.
