# Отчёт проверки версии 1.1.0

Дата: 09.09.2026

## Автоматические проверки

- тесты Vision Installer и границ безопасности;
- тесты ЧебурNET Traffic Control;
- Bash-синтаксис исходного и собранного установщика;
- ShellCheck 0.10.0 для кода Vision;
- компиляция Python-модулей;
- воспроизводимая сборка и контроль встроенного payload;
- автономный запуск через process substitution и `--render`;
- проверка профиля настоящим Xray и отклонение неверного flow;
- проверка HTTP/1.1, HTTP/2, TLS 1.3, SNI и VLESS в локальном интеграционном стенде.

## Живые проверки на Ubuntu 24.04

На чистом сервере подтверждены:

- установка обязательных пакетов и `full-upgrade` с новым ядром и зависимостями;
- сохранение текущего и нового SSH-входа при socket activation;
- установка Docker, nginx, Fail2ban и ZRAM;
- BBR/fq, conntrack, RPS и самопроверка после перезагрузки;
- ограничение API TCP/2222 IP-адресом панели;
- получение сертификата Let's Encrypt и успешный `certbot renew --dry-run`;
- отсутствие постоянного правила TCP/80;
- запуск RemnaNode, Xray и двух Unix-сокетов;
- работа HTTP/1.1 и HTTP/2 через TLS 1.3 и отклонение TLS 1.2;
- установка трёх списков Traffic Control, автозапуск, таймер и самодиагностика;
- восстановление всех служб, контейнера и фильтрации после перезагрузки;
- итоговая самопроверка продвинутой настройки: `OK=13`, `WARN=0`.

Phased updates Ubuntu штатно не форсируются. Внешнее подключение панели и настоящий VLESS-клиент проверяются оператором отдельно, поскольку для них нужны рабочие данные Remnawave.
