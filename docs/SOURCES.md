# Источники и встроенные компоненты

- ЧебурNET Vision Installer `1.1.3` — основной установщик.
- ЧебурNET Auto Tuning `1.0.0` — закреплённый встроенный снимок.
- ЧебурNET Traffic Control `1.0.0` — закреплённый встроенный снимок с тремя внешними списками.
- Remnawave Node `3.4.1` — закреплённый образ контейнера.
- Xray `26.7.28` — проверенная версия внутри образа ноды.

Сборщик проверяет SHA-256 встроенных компонентов, создаёт воспроизводимый архив и добавляет его в единый установочный файл. Установщик не изменяет системный выбор семейства IP.

Аудит 11.09.2026 внёс локальные исправления в оба встроенных снимка 1.0.0. Точные SHA-256 зафиксированы в `build.py`; номера upstream-компонентов сохранены, но файлы больше не заявляются побайтовыми копиями upstream. См. [отчёт аудита](AUDIT-2026-09-11.md). Релиз 1.1.3 и его тег этой работой не обновляются.
