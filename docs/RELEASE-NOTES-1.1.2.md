# ЧебурNET Vision Installer 1.1.2

Исправленный выпуск по результатам аудита. История и предыдущие релизы сохранены.

- Атомарная подготовка каталога ноды, сохранение bootstrap-файлов и продолжение после прерванной установки nginx/служб
- Полный план APT с версиями, повторное согласие при изменении плана и запрет автоматического удаления пакетов
- Одинаковая строгая проверка UFW после тюнинга и до запуска API, включая IPv6
- Явная остановка при ошибке чтения NAT; неизвестные DNAT/REDIRECT требуют ручного разбора
- Проверки ACME-хуков при удалённой или повреждённой установке
- Изоляция полей os-release, смешанный регистр директив SSH, проверка основного sources.list
- `--version`, отклонение лишних аргументов, код 2 при ожидании профиля и видимые интерактивные приглашения
- Единая диагностика Traffic Control, синхронизация записей конфигурации и явный UTF-8
- Обновлённые инструкции, описание ограничений восстановления и оформление схемы Vision без разделительной линии перед изображением

Auto Tuning 1.0.0 и Traffic Control 1.0.0 оставлены побайтово без изменений. Формат профиля и сайт «Тихая Среда» сохранены.

Проверки и их ограничения описаны в `docs/TEST-REPORT.md`. Полный повторный прогон 1.1.2 на чистой VPS не выполнен: нужны проверка SSH, установки, перезагрузки и ACME в реальной среде.

Это не команда обновления работающей ноды. `--resume` продолжает установку той же версии; старую ноду не нужно переустанавливать ради обновления README или сайта.
