# ЧебурNET Vision Installer 1.1.5 — следующее изменение

## Совместимость и установка

- Для Debian 13 используется реальный пакет `bind9-dnsutils` вместо виртуального `dnsutils`
- `python3-systemd` устанавливается явно; Fail2ban переключается на backend `systemd`, если `/var/log/auth.log` отсутствует
- Неинтерактивная установка пакетов и ожидание блокировки dpkg сохранены для обычной установки и `--resume`
- Остаточный защищённый staging-каталог после SIGKILL удаляется только после проверки пути, владельца и режима доступа

## Цепочка доверия

- По выбору владельца новая установка использует `remnawave/node:latest`; после загрузки образ закрепляется по дайджесту SHA-256. `--resume` сохраняет уже закреплённый образ. Это не автоматическое обновление работающих серверов и не гарантия совместимости будущих версий
- Отпечаток официального ключа репозитория Docker сверяется со значением `9DC858229FC7DD38854AE2D88D81803C0EBFCD88`
- Повторный `apt update` Docker выполняется общей безопасной APT-обёрткой

## Сеть и диагностика

- Публичные A/AAAA-адреса самой ноды автоматически добавляются в правило `BLOCK`, чтобы VPN-клиенты не обращались через ноду к её SSH и API
- Из списка блокировки аналитики убраны веб-интерфейсы `analytics.google.com` и `metrika.yandex.ru`; добавлены домены сбора `google-analytics.com` и `mc.yandex.ru`
- Проверки `systemctl is-active` и `is-enabled` теперь сообщают точное имя неработающей службы
- Перед запуском nginx удаляются только два управляемых остаточных Unix-сокета; ошибки nginx направляются в journald

## Сайт-заглушка и обслуживание

- Восстановлена пунктуация многофразовых текстов сайта-заглушки
- При установке выбирается одна из проверенных цветовых тем и добавляется случайный идентификатор варианта, поэтому одинаковые установки не имеют одного хеша HTML
- Импорт генератора запускается с `python3 -B`, чтобы не оставлять `__pycache__` в каталоге ноды
- Исправлена ротация снимков Auto Tuning и удалена пустая f-строка Traffic Control

## Осознанно сохранённые параметры

- `MaxAuthTries 3` остаётся частью согласованного SSH-hardening; после установки обязательно проверяется новый SSH-вход
- `dns.comss.one` остаётся явно заданным резервным DNS профиля; это выбор продукта, а не ошибка установки

Полная проверка чистой VPS обязательна до слияния в `main` и публикации релиза. Уже работающие серверы автоматически не обновляются; `--resume` не является межверсионным обновлением.
