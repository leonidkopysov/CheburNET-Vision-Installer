# ЧебурNET Vision Installer 1.1.5

Исправлена остановка новой установки на шаге усиления SSH после обновления OpenSSH. На некоторых системах с активной SSH-сессией или `ssh.socket` временный каталог `/run/sshd` отсутствует, и проверка `sshd -t` завершается с кодом 255.

- Перед проверкой конфигурации SSH установщик восстанавливает `/run/sshd` с владельцем `root:root` и правами `0755`.
- Способ входа, существующие ключи и правила SSH не меняются этим исправлением.
- Добавлен изолированный регрессионный тест для отсутствующего каталога и повторного запуска.
- Исходники, встроенный архив и SHA-256 синхронизированы воспроизводимой сборкой.

Путь журналов Xray задаётся профилем в Remnawave. Если профиль указывает файл внутри контейнера, каталог для него должен существовать; для отключения журнала доступа используйте значение `none` в профиле. Этот выпуск не изменяет профили панели и не обновляет автоматически уже установленные ноды.
